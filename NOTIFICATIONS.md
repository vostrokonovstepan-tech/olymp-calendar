# Напоминания в Telegram через GitHub Actions

Каждый день в **07:00 МСК** workflow `Напоминания об олимпиадах` проверяет
завтрашнюю дату и присылает начало и окончание этапов, включая незавершённые
регистрации. Однодневный тур получает одно напоминание. Выполненные этапы и
занятия подготовки пропускаются. Если событий нет, бот молчит.

GitHub запускает расписание с возможной задержкой; это не гарантия доставки
минута в минуту. Расписание действует на основной ветке `main`. GitHub может
приостановить cron в публичном репозитории после 60 дней без активности.

## Однократное включение

1. Открыть своего бота в Telegram и нажать **Start** или отправить `/start`.
2. В репозитории открыть **Settings → Secrets and variables → Actions → New repository secret**:
   - `TELEGRAM_BOT_TOKEN` — токен этого бота из **@BotFather**.
   - `TELEGRAM_CHAT_ID` — числовой ID своего личного чата с ботом. Его можно узнать
     как собственный Telegram ID, например у **@userinfobot**. Для личного чата
     ID пользователя совпадает с chat ID. Не использовать имя `@username`.
3. В **Actions → Напоминания об олимпиадах → Run workflow** сначала оставить
   `dry_run` включённым: в логе проверки появится текст на завтра без отправки.
   Для настоящей отправки снять `dry_run` и запустить ещё раз. Если на завтра
   ничего не запланировано, сообщение не отправится.

Токен не вставлять в HTML, переписку, код или адресную строку браузера.
Секреты доступны только серверному заданию GitHub, не посетителям сайта.
Повторный ручной запуск с отправкой повторит сегодняшние напоминания.

## Источник дат

Скрипт читает `SEED` прямо из опубликованной в `main` версии `index.html`,
поэтому отдельную копию расписания редактировать не нужно.
**Личные правки и галочки в Telegram CloudStorage GitHub не видит.** Чтобы они
учитывались в напоминаниях, нужно также обновить календарь в репозитории.
Непроверенные и предварительные даты из календаря остаются предварительными.

## Проверка локально

```sh
node --test scripts/remind.test.mjs
node scripts/remind.mjs --dry-run
```
